# Ferry mock build tour

This is a desktop demo. It uses simulated data and does not call real models.

## Install

1. Download `Ferry-Setup-0.1.0-mock.exe` for the guided per-user installation, or `Ferry-0.1.0-mock-portable.exe` to run Ferry without installing it.
2. If Windows SmartScreen appears, choose **More info** → **Run anyway**. This unsigned demo build has no code signing certificate.
3. For the installer, keep the per-user option, choose an install folder if desired, and finish setup. Ferry adds desktop and Start menu shortcuts.

## Two-minute guided tour

1. **Onboarding (15 sec):** skim the setup, then choose **Skip setup** to enter the demo workspace.
2. **Start a task (15 sec):** enter `Fix the flaky tests` in the message box and send it.
3. **Approve (15 sec):** approve the proposed action when the approval card appears.
4. **Watch the run (25 sec):** follow the simulated handoff to another lane and the checkpoint marker in the transcript.
5. **Open review (15 sec):** select the review entry to inspect the proposed changes.
6. **Explore capacity (15 sec):** open **Explore**, then **Usage**, to view the sample provider and usage data.
7. **Profiles and palette (15 sec):** open **Settings** → **Profiles**, then press **Ctrl+K** to browse the command palette.
8. **Terminal (5 sec):** press **Ctrl+`** to open the bottom terminal panel.

All activity in this build is local simulation; no real model requests are made.
