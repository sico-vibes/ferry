# Ferry v0.10 upgrade plan — Multica + T3 Code learnings

Status: **proposed** (2026-09-29). Ships as rolling betas: every merge to `main` auto-publishes
`0.9.0-beta.N` (later `0.10.0-beta.N`) and installed apps auto-update.

Sources: `docs/research/multica.md` (Multica — source-available: **ideas only, clean-room, no
code**) and `docs/research/t3code.md` (T3 Code — MIT, T3 Tools Inc.: patterns and, where
useful, adapted code **with NOTICE attribution**). Ferry's moat stays routing, quotas, free
tiers and the Gateway — none of this work may regress them.

## Goals

1. **See what the agent is doing:** a live timeline of thinking + tool calls for Ferry's own
   agent and for delegated CLIs.
2. **Use what you already pay for:** models and effort levels from signed-in CLIs appear in
   Ferry's picker, with no token reading.
3. **Work safely in parallel:** worktree per thread, a checkpoint per turn, git actions from
   the UI.
4. **Feel fast and polished:** command palette, virtualized lists, better pickers, plan cards
   and diff review.

## Not now (revisit after v0.10)

- **Event-sourced core rewrite** (command → decider → events → projector, T3 #10): right long-term
  shape, but too large for this cycle. U1 and U15 move toward it incrementally.
- **Web/mobile remote control** (T3 #14): needs authenticated RPC over the network — later.
- **Copying T3's stack** (Effect 4, `@legendapp/list`, 10k-line components): no. Copy shapes, not
  imports.

## How it runs

- **Team:** Claude briefs, reviews and merges; Luna implements (≤4 parallel runs in separate
  worktrees, with `main` pre-merged by Claude); OpenCode does P1 and per-wave QA (one run at a
  time).
- **Gates per item:** full `check`, desktop `test:e2e`, and for anything that touches packaging,
  `dist` + packaged smoke. Screenshots of new UI are attached to each review.
- **Shipping:** each item merges on its own → CI publishes the next beta → the installed app
  auto-updates. Risky items (U6, U8, U12) sit behind an Advanced toggle until verified.
- **Legal:** Multica = ideas only (clean-room). T3 = MIT; add "T3 Code (MIT, T3 Tools Inc.)" to
  `NOTICE` for any adapted code; never copy brand assets.
