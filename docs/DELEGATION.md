# Delegation agents

Fleet lanes may use `implementer: "acp", agent: "<registry id>"` to launch one of the agents in `packages/delegate/data/acp-agents.yaml`. Existing Codex, OpenCode, and Claude CLI lanes keep their native transports by default; set `transport: "acp"` to route a supported agent through ACP.

The registry is the supported-agent source of truth. `ferry doctor` detects available agent CLIs and ACP agents without reading credentials. Install and authenticate each agent using its own official instructions. Pi and `pi-free` are user-installed: install Pi and the pi-free extension, then choose the `pi` ACP agent through `pi-acp`. Ferry does not install Pi or modify its auth files.

ACP file access is limited to the delegation workspace and lane paths. Writes run the configured checkpoint callback before changing a file. Permission requests are forwarded to Ferry's approval callback when one is configured. ACP authentication methods are surfaced to the host, and those credentials remain client-owned. The separate installed-CLI connection can resolve an explicitly selected existing OpenCode credential for its verified transport; Ferry does not enroll another account or copy that credential into its provider-key database. See [CLI connections](CLI-CONNECTIONS.md). Large tool outputs retained for recovery are written to Core's local SQLite `optimizer_blobs` table. Explicit conversation deletion removes matching blobs with a valid session ID; this lifecycle is separate from request/telemetry retention. Blobs orphaned by earlier deletions are not automatically swept. See [optimizer limits](OPTIMIZERS.md) and [current status](STATUS.md).

## Review and decisions

The implementer writes within the task workspace before presenting its result for review. Inspect the diff/output; **Accept** records the decision and leaves the changes in place, while **Reject** restores the pre-delegation checkpoint when one was created. **Rework** resumes the lane session with a delta brief and requires a resumable CLI session; it cannot resume after Ferry restarts. ACP file access is limited to the delegation workspace and lane paths. Writes run the configured checkpoint callback before changing a file. Permission requests are forwarded to Ferry's approval callback when configured. For native CLI lanes, authentication remains in the installed client's store; see [CLI connections](CLI-CONNECTIONS.md).
